VELMAROX.COM - CHANGELOG
Versioning scheme: v#.#.#-[stage] (semver)
Patch = fixes | Minor = new content (patch resets) | Major 0 until launch (v1.0.0)
Stages: -alpha → -beta at feature-complete → -rc1 when launch-ready → v1.0.0 gold
The current version lives in <meta name="version"> in docs/index.html and in the latest entry here.
Git history is the archive: every release is a commit, and old versions can be checked out from it.
