# Saved: the shop as it was

`products.js` here is the product list from v0.6.1-alpha, with the five sample products and the
`PRODUCTS` format the shop page reads. It is outside `docs/`, so it is not on the website.

To open the shop:
1. In `docs/js/data/products.js` set `window.SHOP_OPEN = true`.
2. Fill `window.PRODUCTS` with real products. Copy entries from this file as a starting point,
   drop `sample: true`, and put real `link`s and images in.
The shop grid, type filters, Buy / Coming soon / Sold out buttons and the home page "From the shop"
row all come back as they were.
