Last night at about 8:30 I yelled at my computer. Full caps lock, no punctuation, a run-on sentence with three demands in it.

About ten seconds later I said sorry to it.

I apologized to the computer. I'm not going to pretend I didn't.

What happened

I'm building Datcord, a small app that backs up a Discord server. To talk to Discord it needs a bot token, which is basically a password. You paste it in once and the app remembers it.

It remembered it a little too well. Once a token was in, there was no way to change it. No settings, no menu, no button. The app had decided it knew best and I was locked out of my own app.

I'd already changed my mind about how chat logs should work, I'd asked for an installer that wouldn't eat my saved copies, and then I opened the thing and it wouldn't let me type a password. That was the moment the caps lock came on.

The yelling was the bug report

Here's the funny part. Under all the shouting, that message was a perfect bug report.

  • What's broken: I can't put my token in again.
  • What I need: a menu bar with settings.
  • Why: so I can actually use it.

Somebody calm would have written that more nicely. They wouldn't have written it more clearly.

The next version, 0.8, gave the app a File, Settings and Help menu, and a Bot token option under Settings with Paste and Show buttons. Then I kept going: 0.9 let me choose which channels get saved, 0.10 added automatic backups and a progress bar, and 0.11 was a proper installer with an uninstaller. Four versions after the yelling. Same evening.

The computer had to try again too

I wasn't the only one failing that night. Building the installer, the first thing the setup tried didn't work. The official place to get Python was blocked, so it had to go find it somewhere else. Then it tried to click through the install wizard to test it and kept missing the buttons, because the window opened somewhere it didn't expect.

It didn't yell, but it did try again. A few times. And the installer exists now.

So here's my advice

If at first you don't succeed, you're allowed to be mad about it. Type in all caps. Say the thing. Making stuff is frustrating, and acting like it isn't doesn't make you better at it.

Just don't stop there. The scream isn't the end of the work, it's usually where you find out what the work actually is. Mine told me exactly what was missing. Then I apologized, because I was raised right, and then I tried again.

Four versions later, it has a menu bar and an installer. lol.
