Last night around 8:30, I yelled at my computer. Caps lock on, no punctuation, one long sentence with three demands in it. Then I said sorry to it. Out loud. To a computer.

The problem

Datcord is a small Windows app I'm making that backs up a Discord server: the channels, the roles, and now the chat logs. To talk to Discord it needs a bot token, which is basically a password. You paste it in once and the app remembers it.

It remembered it too well. Once a token was saved, there was no way to change it. No settings screen, no menu, no button. If I needed a different token, too bad. The app had decided it knew best, and I was locked out of my own app.

On top of that, the exe on my desktop and the shortcut pointing at it were still the old version. So every time I opened the app to check whether things were better, I got the same old app that still wouldn't let me type a password.

That was the moment the caps lock came on.

The yelling was the bug report

Here's the funny part. Under all the shouting, it was a perfect bug list:

  • The exe and the desktop shortcut were out of date.
  • I couldn't put my token in again.
  • The app needed a menu bar with settings, so I could actually use it.

Somebody calm would have said that more nicely. They wouldn't have said it more clearly.

The fix

Version 0.8 got a menu bar: File, Settings and Help. Settings has a Bot token option, with a Paste button and a Show button so you can check what you put in. The token isn't stuck anymore.

Then I kept going. 0.9 lets you choose which channels get their chat saved. 0.10 added automatic backups and a progress bar. 0.11 is a proper installer with an uninstaller, so updating means running one file instead of wondering which exe is the real one. Four versions after the yelling. Same evening.

So here's my advice

If at first you don't succeed, you're allowed to be mad about it. Type in all caps. Say the thing. Making stuff is frustrating, and acting like it isn't doesn't make you better at it.

Just don't stop there. The scream isn't the end of the work, it's usually where you find out what the work actually is. Mine told me exactly what was missing. Then I apologized, because I was raised right, and then I tried again.

Four versions later, it has a menu bar and an installer. lol.
